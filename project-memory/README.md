# PnWind 项目记忆

本目录是 PnWind 项目唯一的记忆位置。在本仓库工作的 AI agent 开始之前，先读根目录的 `AGENTS.md`，再读本文件和下面的条目；人也适用。

`AGENTS.md` 是操作手册：目录、命令、怎么写一个页面、数据库的写法、红线。这里是规矩和它们的理由，两边有出入时以这里为准。

## 规范与约束

- [开发规范与约束](规范/开发规范与约束.md) — 写代码要守的准则和约束：六个词的代码准则、内核和业务的边界、不精简掉已有的功能、优雅退出的红线、分区表和时区、三个系统都要过、编译产物和日志的约定
- [agent 工作规范与约束](规范/agent工作规范与约束.md) — AI agent 和维护者配合的工作方式：用中文并随时汇报、只做点名的事、建议配具体对照、疑点只报告、删之前说清换成什么、改完先问要不要测、测试服务不碰正式的服务、凭据不外流、少用子代理

## 往这里加东西

- 新定下的规矩、项目的状态，一条一个文件放进本目录，再在本文件里加一行索引：标题和一句话摘要。不写到别处。
- 文件开头照现有两份的写法，带上 `name`、`description` 和类型。
- 规矩变了，`AGENTS.md`、这里、`core/CORE.md` 里说同一件事的几处一起改。
